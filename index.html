Generative model efficiency

Looped Diffusion

Image diffusion models repeat one set of weights instead of stacking dozens of distinct layers. The result is a 69-million-parameter backbone that matches a published transformer of identical size while doing roughly a quarter of the arithmetic per step.

0.28× compute 497 vs 1787 GMAC per forward pass

Where the parameters go

A looped backbone spends almost everything on the block that repeats. Getting a convolutional block to the same budget as the transformer it is compared against took shrinking the conditioning path and widening the feature dimension to compensate — the two moved together until the counts lined up.

Removing 22.4M parameters — a quarter of the model — moved FID by 0.15, while sFID and recall both improved. The reference transformer's figure is its published result at five times the training budget.

Method

Weight sharing across depth is an old idea that has mostly been applied to transformers. This work asks what happens in a convolutional backbone, where a 7×7 depthwise convolution replaces attention and costs two orders of magnitude fewer parameters for the same job of mixing spatial positions. That saving is what funds the wider feature dimension needed to hit the parameter target.

The compute figure comes from the reference model's own published per-layer arithmetic: 111.7 GFLOP across 32 layers, or 1787 GMAC per forward pass. The convolutional model runs 497. Most of that difference is tokenization — 256 positions against 1024 — and the rest is the absence of attention.

Status

Training is paused at roughly 150,000 of a planned 500,000 steps. Checkpoints, training curves and evaluation reports are archived; the recovery path has been verified end to end, including resuming training from an archived checkpoint and reproducing samples from it.

Next is extending the run toward the reference model's training budget so the comparison is like-for-like, and generalising the implementation from one shared block to several — the axis the reference paper is built around, and the one this implementation cannot currently test.
